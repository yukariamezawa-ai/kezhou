## 🌟 它能为你做什么？

### 🎬 1. 0 延迟秒采，把好灵感随手装进口袋
* **全网主流平台直达**：原生探索主页内置 Sora、Runway Gen-3、可灵 (Kling)、Civitai 等平台快捷入口与运镜快筛标签；
* **顺手秒采胶囊**：浏览任意网页或视频播放时，点击悬浮的「捕获灵感」胶囊，无需跳转即可自动抓取封面、作者与高清源；
* **提示词工坊 (Prompt Studio)**：分镜一键格式化导出，快速为画面注入 `+推镜头`、`+变焦`、`+丁达尔光`、`+赛博朋克` 等电影级修饰词，直接流转至 Midjourney 或剪辑软件。

### ⚡ 2. 视频离线管饱，基础体验永久免费
* **日常 1080P / 720P 毫不吝啬**：日常清晰度完全开放，无限次使用，不设任何暗门扣费限制；
* **多音轨与画质随心选**：支持单独提取背景纯音频（MP3/M4A/FLAC）或下载字幕；
* **极速后台引擎**：基于成熟通用的解析架构与多线程加速，下大文件稳健不掉线。

### 🛡️ 3. KuroBox 私密地窖：借手机给别人也不心慌
* **相册完全隐形**：离线文件默认写入应用私有沙箱，配合底层 `.nomedia` 守护，**手机自带相册、第三方看图软件、微信选图窗口完全看不到**；
* **通知栏脱敏保护**：后台下载时，手机状态栏只显示冷冰冰的进度条与中性词，绝不会把视频标题、敏感 URL 或封面大喇喇地挂在通知栏上；
* **防随手翻看双暗号**：桌面图标与名称是干干净净的“浏览器”。真正放私密文件的地窖入口藏在地址栏专属暗号（`kezhou://vault`）或版本号连续轻敲 5 次之中，配合 PIN 码门禁，万无一失。

## ❓ 常见疑问与解答

<details>
<summary><b>Q1: 为什么我下载的视频在手机自带相册里找不到？</b></summary>
<br/>
这正是刻舟最核心的隐私设计！如果你存了私人素材或工作分镜，肯定不希望在给家人朋友翻看相册、或者在微信发图时不小心滑出来造成社死。视频保存在刻舟独立的私有地窖内，如果你确实需要导出到系统相册，在分镜详情页随时可以点击「导出至系统相册」。
</details>

<details>
<summary><b>Q2: 以后基础功能真的不会突然反悔收费吗？</b></summary>
<br/>
请放心，绝不反悔。做这个项目的初衷就是受够了市面上各种工具“刚用两天就收门票”的吃相。1080P/720P 基础离线、AI 分镜采摘和提示词功能会一直免费开放下去。
</details>

<details>
<summary><b>Q3: 安装时系统提示「未知来源应用」安全吗？</b></summary>
